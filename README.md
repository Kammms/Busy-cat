# **Privacy Policy**

**Last updated:09/07/2026**

This bot tracks moderator activity and manages a points‑based leaderboard, as well as shop transactions performed by moderators on behalf of server members. All data processing is limited to what is required for these features to function.

---

## **Data We Collect**
The bot only collects and processes Discord‑provided data necessary for activity tracking and shop management:

- Discord **user IDs** and **usernames** of tracked moderators and shop buyers  
- **Message counts**, **voice channel activity hours**, and **invite counts** within servers where the bot is active  
- **Points**, **manual point adjustments**, and **leaderboard rankings**  
- **Shop purchase records**, including items bought, payment type, reported balance, and role/expiry information

The bot does **not** collect any personal information outside of Discord’s API.

---

## **How We Use the Data**
Collected data is used exclusively for:

- Calculating and displaying moderator points and leaderboards  
- Managing shop purchases and automatically expiring temporary roles  
- Allowing server administrators to configure, review, and audit activity tracking and shop logs through the dashboard or bot commands

All processing is strictly limited to the bot’s functionality inside Discord.

---

## **What We Don’t Do**
To protect user privacy, the bot explicitly does **not**:

- Read, store, or analyze the **content** of member messages — only numerical activity counts  
- Access or store direct messages (DMs)  
- Share, sell, or transfer data to third parties  
- Use any collected data for advertising, analytics, or profiling  
- Monetize any feature — the bot is fully funded and maintained by its creator, and no payments or donations are required or accepted

---

## **Data Retention & Removal**
Data is retained only while the bot remains active in a server.

- Server administrators may exclude a moderator from tracking at any time using `/set exclude`.  
- Users or moderators may request deletion of their stored data by contacting the server administrator responsible for managing the bot.  
- If the bot is removed from a server, all associated data is deleted as part of the cleanup process.

---

## **Contact**
For questions or data‑related requests, please contact the server administrator or the bot owner.
